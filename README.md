# 我的工具箱

> 手机随时翻。每个项目一句话说清「你为什么需要它」。

## 电脑：重装、清理、激活

- **winutil** — Chris Titus 的 Windows 工具箱，一条命令装常用软件、关遥测、清垃圾。重装系统后第一个跑的就是它。
  https://github.com/ChrisTitusTech/winutil
- **Microsoft-Activation-Scripts** — MAS，开源激活脚本。重装完不用再到处找 KMS 工具。
  https://github.com/massgravel/Microsoft-Activation-Scripts
- **Ventoy** — 一个 U 盘装多个 ISO，插上开机就能选。以后装系统不用来回刻盘。
  https://github.com/ventoy/Ventoy

## 手机与远程

- **scrcpy** — 电脑上直接操作安卓手机，低延迟、免 root。改设置、回消息比投屏软件快得多。
  https://github.com/Genymobile/scrcpy
- **termux-app** — 手机上的 Linux 终端。你部署 Ollama、跑脚本都靠它。
  https://github.com/termux/termux-app
- **RustDesk** — 开源自建远程桌面，替代 TeamViewer / UU 远程。
  https://github.com/rustdesk/rustdesk

## AI

- **ollama** — 一条命令跑本地大模型。你手机上试过，电脑上更该有一份。
  https://github.com/ollama/ollama
- **Open WebUI** — 给 ollama 套一个网页聊天界面，比命令行舒服，支持多会话和历史。
  https://github.com/open-webui/open-webui

## 学习

- **Anki** — 间隔重复记忆卡。背单词、公式、专业名词，比你手抄一遍强。
  https://github.com/ankitects/anki
- **manim** — 数学动画引擎，3Blue1Brown 用的就是它。把函数图像动起来看，比硬背强。
  https://github.com/ManimCommunity/manim

## 效率与阅读

- **思源笔记** — 中文开源笔记，本地存储、双链、块引用。
  https://github.com/siyuan-note/siyuan
- **Koodo Reader** — 多端电子书阅读器，EPUB / PDF / MOBI 都吃，进度能同步。
  https://github.com/koodo-reader/koodo-reader
- **yt-dlp** — 命令行视频下载，B 站、YouTube 都行。比网页解析工具稳。
  https://github.com/yt-dlp/yt-dlp

## 怎么用

手机上打开这个页面就是清单，点链接直接进项目主页。

电脑上要装哪个：进项目主页 → Releases 下 exe，或者 `git clone` 下来自己编译。
